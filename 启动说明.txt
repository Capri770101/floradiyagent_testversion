====================================================
  跳舞兰 · 花艺工坊 — 本地启动手册
  （后端 FastAPI 8080 + 前端 Vite 5173）
====================================================

【使用前提】
1. 已安装 Python 3.10+ 和 Node.js 18+
2. 已安装依赖：
   - 后端依赖（在项目根目录执行）：
     pip install -r misc/requirements.txt
   - 前端依赖（在 H5 目录执行）：
     npm install
3. 已配置 misc/.env（含 LLM_API_KEY，DB 路径等；此文件已被 .gitignore 忽略）

----------------------------------------------------
【一、启动后端】（端口 8080，需单独开一个终端窗口）
----------------------------------------------------
cd C:\Users\Capri\Desktop\flora_diy_agent
python -m uvicorn backend.api:app --host 127.0.0.1 --port 8080

验证：浏览器打开 http://127.0.0.1:8080/health
      应返回 {"status":"ok",...} 即启动成功。

----------------------------------------------------
【二、启动前端】（端口 5173，另开一个终端窗口）
----------------------------------------------------
cd C:\Users\Capri\Desktop\flora_diy_agent\H5
npm run dev

看到 Vite 提示 Local: http://localhost:5173/ 即启动成功。

----------------------------------------------------
【三、访问三端】
----------------------------------------------------
C 端（顾客/下单/小兰AI） : http://localhost:5173/
商家端                   : http://localhost:5173/merchant.html
管理端                   : http://localhost:5173/admin.html

（本地 dev 同源，前端 Vite 已代理 /api → 后端 8080）

----------------------------------------------------
【六、常见问题】
----------------------------------------------------
1) 后端启动失败提示缺 LLM_API_KEY：
   检查 misc/.env 是否配置了 LLM_API_KEY。
   无 key 时 agent 会走规则引擎兜底，聊天仍可用，
   但语义化定制方案会降级。

2) 端口被占用：
   - 8080 被占：先杀占用进程再启动后端
     Get-NetTCPConnection -LocalPort 8080 -State Listen |
       ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
   - 5173 被占：同理替换端口号。

3) 数据库文件：
   首次启动后端自动创建 data/agent_service.db 并灌种子数据。
   如需重置演示数据，删除 data/ 目录下的 .db 文件后重启后端。

4) PowerShell 中文乱码：
   终端输出中文乱码是 GBK 控制台显示问题，不影响功能。
